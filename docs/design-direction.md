# Visual direction

Vampir Köylü uses a cinematic 2D dark-village presentation.

Core rules:
- 16:9 desktop composition with responsive mobile adaptation.
- Warm fire and lantern light against cool moonlit backgrounds.
- Gothic wood/parchment UI without sacrificing readability.
- Character portraits form a village council instead of a 3D movement map.
- Claims, conflicting claims, voting history and private notes are first-class UI.
- The interface organizes evidence but never decides who is truthful for the player.
- Night and day reuse the same village spatial language so phase changes feel continuous.
